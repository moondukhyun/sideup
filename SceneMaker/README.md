LoopMaker 쪽은 `LoopMaker_v9.py`(v11.19 최신)로 교체하면 [AI 배경] 탭에 `젖은 바위·물줄기·수면 빗방울` 체크가 생깁니다.
**LoopMaker 와 SceneMaker 파일은 함께 교체**해야 합니다 (옵션 이름이 서로 맞아야 함).

## 무엇이 고쳐졌나
1. **잎이 안 흔들리던 원인**: 장면 설정에 `splashes: False` 가 있으면 코드가 잎 흔들림까지 통째로 건너뛰었음
   (valley_stream, forest_lake, rain_leaves, cabin_window, hanok_cafe). 이제 잎 흔들림은 따로 판단.
   - GUI 에서 `물 튀김·물결·물방울` 만 끄고 `잎 흔들림` 을 켜 둬도 예전엔 잎이 안 흔들렸는데, 이것도 같은 원인.
2. **바위가 젖는 효과**: 코드에 없었음 → 새로 추가 (어둡고 또렷한 젖은 돌 + 반짝임 일렁임 + 흘러내리는 물줄기).
3. **수면 빗방울 물결**: `waterrain.py` 가 있었지만 어디에서도 호출되지 않았음 → 계곡·저수지 씬에 연결.

## 확인용 파일
영상을 만들면 작업 폴더에 `wet_mask.jpg`(젖은 바위로 인식한 곳을 빨갛게 표시)가 생깁니다.
바위가 아닌 곳이 칠해졌거나 바위가 빠졌으면 알려주세요 (기준값을 조정합니다).

## 다른 씬에도 쓰려면 (scenes.py)
해당 씬의 비 설정(dict)에 `"wet": 1.0`(젖은 바위·물줄기), `"water_rain": 1.0`(수면 빗방울)을 추가하세요. 0 이면 꺼짐.
