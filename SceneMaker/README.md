## v11.21 (2026-10-18) — 빗줄기가 이미지에 박히던 문제 + 모든 표면에서 빗물 흘러내림 + 대롱 물줄기 흐름
| 문제 | 원인 | 해결 |
|---|---|---|
| 영상에 빗줄기가 **고정된 그림**으로 남음 | 배경 이미지를 만들 때 프롬프트에 `heavy downpour`·`in the rain` 등이 들어가 AI 가 빗줄기를 이미지에 그림 | 모든 장면 프롬프트의 비 표현을 '젖은 흐린 날'로 바꾸고(`scenes.dry_prompt`), 비 세기 문구(`variety.py`)도 젖은 정도로 변경. 네거티브에 빗줄기 금지 추가. (22개 장면 × 3520개 조합 검사: 비 단어 0개) |
| 대롱 물줄기가 **멈춰 있음** | 정지 이미지에 그려진 물줄기라 움직임이 없음 | `streamflow.py`: 물줄기를 찾아 위→아래로 흐르는 줄무늬를 입힘 + 떨어지는 곳에 물결·튀는 물. 대나무 정원 기본 적용 (`stream` 설정) |
| 돌·대나무·정자 지붕/기둥에서 **빗물이 안 흘러내림** | 흘러내림 효과가 계곡 바위에만 있었음 | 모든 장면 기본 적용(`wet` 0.7): 돌·기와·벽·기둥 표면의 젖은 질감 + 빗물 줄기 + **대나무·나무·기둥 줄기를 따라** 흘러내리는 물방울 |

※ 이미 만든 배경 이미지에는 빗줄기가 박혀 있으니 **배경을 새로 만들어야** 합니다(이 업데이트 이후 만든 이미지부터 깨끗합니다).
영상을 만들면 작업 폴더에 `stream_mask.jpg`(물줄기로 인식한 곳, 하늘색)·`wet_mask.jpg`(젖은 표면=빨강, 줄기 물줄기=노란 선)가 생깁니다.
대롱 물줄기가 인식되지 않으면 로그에 안내가 나오며, 이때는 Wan(💧 물·안개 AI 움직임)을 켜 보세요 (대나무 정원은 Wan 에 '대롱에서 물이 쏟아져 대야로 떨어짐' 설명이 기본으로 들어갑니다).
다른 장면에서 물줄기 흐름을 쓰려면 scenes.py 의 비 설정에 `"stream": 1.0` 을 추가하세요.

## v11.20 사실감 업그레이드 (실제 촬영처럼)
| 항목 | 이전 | 이후 |
|---|---|---|
| 창문 물방울 | 1~2px 점이 거의 안 보임 | 3~24px 방울 + 안개 방울, 면적의 약 10% 덮임, 풍경이 거꾸로 맺히고 테두리·반사광 |
| 흘러내리는 방울 | 8초에 50~170px 기어감, 흔적 거의 없음 | 멈춤↔순간 미끄러짐 반복(약 300~800px), 물길 + 남은 작은 방울, 지나간 자리의 방울을 쓸어 담음, 김서림이 맑아짐 |
| 빗줄기 | 길이·굵기·기울기가 일정 | 바람에 따른 기울기 변화(돌풍), 굵기 변화, 끝이 흐려지는 번짐, 밝은 빛 주변 비가 더 밝게 번쩍임 |

| 창가 장면 | `cafe_window` 만 유리 효과 | `cabin_window`(산장)·`hanok_cafe`(한옥 카페)도 유리 효과 |

영상을 만들면 `glass_mask.jpg`(유리로 인식한 영역, 파란색)·`wet_mask.jpg`(젖은 바위, 빨간색)가 작업 폴더에 생깁니다.
설정으로 세기 조절 (scenes.py 의 비 설정 또는 config.toml `[rain]`): `gust`(돌풍) `bloom`(번짐) `wet_ground`(젖은 바닥) 0 이면 끔.

## 무엇이 고쳐졌나 (v11.19)
1. **잎이 안 흔들리던 원인**: 장면 설정에 `splashes: False` 가 있으면 코드가 잎 흔들림까지 통째로 건너뛰었음
   (valley_stream, forest_lake, rain_leaves, cabin_window, hanok_cafe). 이제 잎 흔들림은 따로 판단.
   - GUI 에서 `물 튀김·물결·물방울` 만 끄고 `잎 흔들림` 을 켜 둬도 예전엔 잎이 안 흔들렸는데, 이것도 같은 원인.
2. **바위가 젖는 효과**: 코드에 없었음 → 새로 추가 (어둡고 또렷한 젖은 돌 + 반짝임 일렁임 + 흘러내리는 물줄기).
3. **수면 빗방울 물결**: `waterrain.py` 가 있었지만 어디에서도 호출되지 않았음 → 계곡·저수지 씬에 연결.

| `hearth_dog_cat` | 벽난로 앞에서 자는 반려견·반려묘 |

새 파일: `interior.py`(촛불·불꽃·불빛·숨쉬기), `ambience.py`(벽난로·빗소리 합성). 수정: `cli.py rain.py scenes.py variety.py video.py`.

- 촛불: 그림에서 작고 밝은 불꽃을 자동으로 찾아 흔들리게 하고, 방 안 벽·가구에 닿는 불빛이 같이 일렁입니다.
- 벽난로: 크고 주황·노란 불 덩어리를 찾아 타오르게 하고 불티를 날립니다.
- 반려동물: 자동으로 못 찾기 때문에 LoopMaker 의 `🐾 반려동물 위치 지정` 으로 상자를 그리면(작업 폴더 `pets.json`) 숨쉬듯 움직입니다.
  CLI: `--pet 0.52,0.80,0.68,0.93,dog` (0~1 비율, 여러 번 가능)
- 소리: 벽난로 장면은 타닥거리는 소리를 자동 합성(`--no-fire-sound` 로 끔, `--fire-db -6` 로 작게). 녹음한 빗소리가 없으면 창가 빗소리도 합성.
  따로 만들기: `python -m scenemaker ambience --kind fire+rain --seconds 90 --out amb.wav`
- 확인용 파일: `interior_mask.jpg` (노란 원=촛불, 빨간 상자=벽난로 불, 하늘색 상자=반려동물), `glass_mask.jpg` (창)
- 천장 선풍기: `🐾 반려동물·선풍기 위치 지정` 에서 '천장 선풍기' 를 고르고 날개 전체를 상자로 감싸면 천천히 돌아갑니다 (CLI: `--pet x0,y0,x1,y1,fan`). 가운데 몸통은 고정, 날개만 회전·흐려짐.
- v11.22 보정: 창 유리는 색(푸른 창밖 vs 따뜻한 실내)으로 찾아 벽·침대·창살에는 물방울이 안 맺힘 / 큰 방울이 먼저·빠르게·구불구불 흐름 / 촛불은 불꽃만 아주 살짝, 장작불은 천천히 / 반려동물 숨쉬기 폭 확대
- v11.22 AI 움직임(실내): `--wan` 을 켜면 벽난로 불·촛불은 Wan 2.2 가 만든 픽셀로, 반려동물 숨쉬기는 Wan 의 움직임(흐름)만 원본 사진에 입힘 (`wanroom.py`, `--wan-clips N` 클립 수). 실패하면 수식 움직임으로 자동 대체.
- 반려동물·선풍기 위치: LoopMaker 가 Claude 로 자동 찾기(`🤖 자동 찾기`) → `pets.json` 저장. 장작 소리는 기본 -12dB (`--fire-db`).
