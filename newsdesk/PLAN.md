# somnia-forest 성장 계획서 (v1)

> 한계: 작성 환경에서 YouTube에 접속할 수 없어 채널 실제 지표(조회수·시청 지속시간·트래픽 소스)는 **미확인**입니다.
> 아래 진단은 일반적인 빗소리 채널 구조에 근거한 가설이며, YouTube Studio 데이터로 검증해야 합니다.

## 1. 수익 $0.01의 진짜 원인 (가설)
수익 = 조회수 × RPM. RPM이 낮은 것보다 **조회수 자체가 부족**한 것이 1차 원인일 가능성이 큽니다.
빗소리/수면 콘텐츠는 광고가 적게 붙고(수면 중 시청, 광고 없는 시간 多) RPM이 낮은 편이라, 같은 방식으로는 조회수를 늘려도 한계가 있습니다.
→ 확인할 것: Studio > 분석 > 도달(노출수, 클릭률), 참여(평균 시청 지속시간), 트래픽 소스(검색/추천/외부).

## 2. "핫뉴스 자동 방송"에 대한 솔직한 평가 — 그대로 하면 위험
| 방식 | 위험 |
|---|---|
| 뉴스 영상/기사 자동 수집 후 그대로 업로드 | 저작권 침해, YouTube의 **반복적/대량 생산 콘텐츠(inauthentic content) 정책**으로 수익화(YPP) 박탈 가능 |
| AI가 쓴 뉴스를 검수 없이 송출 | 오보·허위 위험, 명예훼손, 채널 신뢰 하락 |
| 사건·사고·정치 뉴스 | 광고 제한(노란 딱지), 수익 감소 |

핵심은 **"뉴스를 퍼 나르는 채널"이 아니라 "뉴스를 차분하게 해설해 주는 빗소리 채널"** 로 포지셔닝하는 것입니다.
사람의 목소리·관점·편집이 들어가야 정책상 안전하고, 차별화도 됩니다.

## 3. 권장 컨셉: "빗소리와 함께 듣는 차분한 오늘의 이슈"
- 자극적이지 않은 이슈(날씨·계절·생활·경제 상식·과학·문화) 위주 5~10분 브리핑 + 이후 빗소리 연장
- 검색 유입 확대: 날씨/장마/태풍 같은 **빗소리와 자연스럽게 연결되는 이슈**가 1순위
- 쇼츠(30~50초 요약)로 신규 유입 → 롱폼(빗소리 + 브리핑)으로 시청시간 확보
- 별도로 유지: 8시간 수면용 빗소리, 24시간 라이브(시청시간 4,000시간 유지에 유리)

## 4. 에이전트 역할 분담 (이 저장소 `newsdesk/` 가 담당하는 부분 표시)
| 역할 | 하는 일 | 구현 |
|---|---|---|
| 트렌드 스카우트 | Google Trends/뉴스 RSS 수집, 민감 주제 필터, 중복 제거 | `lib.mjs` ✅ |
| 에디터 | 출처 기반 요약·대본·제목·썸네일 문구·설명·태그 초안 | `run.mjs` ✅ |
| 팩트체커 | 추측 금지 규칙 + 검증 체크리스트 출력 | 프롬프트 ✅ / **최종은 사람** |
| 편집자(사람) | 검수·녹음·영상 편집·업로드 | 수동 (의도적) |
| 분석가 | 업로드 후 CTR·지속시간 점검, 다음 주제 조정 | 수동 → 2단계에서 YouTube Analytics API |

자동 업로드는 **일부러 만들지 않았습니다.** 검수 없는 자동 송출이 가장 큰 정책·신뢰 리스크입니다.

## 5. 실행 로드맵
1. **1주차**: Studio에서 지표 3종 확인 → 공유해 주시면 가설 검증. `run.mjs`로 초안 3개 생성·검수·업로드(시범).
2. **2~4주차**: 주 3회(롱폼 1 + 쇼츠 2). 제목/썸네일 A/B(Studio 테스트 기능).
3. **2단계**: YouTube Data/Analytics API 연동으로 성과 리포트 자동화, 자막(SRT) 생성.
4. **병행**: 티스토리에 같은 주제의 검증된 글(출처 명시) 게시 → 영상 설명란 연결.

## 6. 사용법
```
node newsdesk/test.mjs                              # 파서 테스트
ANTHROPIC_API_KEY=sk-... node newsdesk/run.mjs 3    # 초안 3건 → newsdesk/out/날짜/
```

## 7. 보안 주의 (기존 코드)
`api/claude.js` 는 인증 없이 `CORS: *` 로 열려 있어, 주소를 아는 누구나 사용자 API 키로 호출해 **요금을 소모**시킬 수 있습니다.
허용 도메인 제한/간단한 토큰 검증/max_tokens 상한을 권장합니다.

# 8. 실제 데이터 진단 (YouTube Studio, 2026-09-11 ~ 10-08, 28일)

| 항목 | 값 |
|---|---|
| 조회수 / 시청시간 / 예상수익 | 9,048회 / 239시간 / US$1.94 |
| 구독자 | 39,744명 (28일 순증감 -50, 신규 +12) |
| 월간 시청자 | 2.6천 명 (신규 96.1%, 일반 3.6%, **고정 0.3%**) |
| 형식별 조회수 | Shorts 6.3천(69.8%) · 라이브 2.3천(25.0%) · 게시물 243 · 동영상 227 |
| 게시한 콘텐츠 | 라이브 8 · Shorts 7 · 동영상 3 · 게시물 1 |
| 트래픽 소스 | Shorts 피드 63.2% · 탐색 16.0% · 검색 8.9% · 추천 8.9% · 채널 1.5% |
| 노출수 / 클릭률 | 11만 / 0.9% |
| 썸네일 클릭 유입 | 조회 996회, 평균 6:30, 시청시간 107.92시간 |
| 시청자 | 한국 85.5% · 55세 이상 75% (45~54세 25%, 그 미만 0%*) · 여성 54% |
| 기기 | 휴대전화 61.3% · TV 18.5% · PC 10.2% · 태블릿 10.0% |
| 자막 언어 | 자막 없음 98.4% |

\* 연령은 YouTube 추정치이므로 "0%"는 표본이 작아서일 수 있습니다.

## 핵심 해석
1. **롱폼·라이브가 시청시간을 만든다.** 썸네일 클릭 유입은 전체 조회의 약 11%(996회)인데 시청시간은 107.9시간으로 전체 239시간의 약 45%입니다. Shorts는 조회가 많아도 수익과 시청시간 기여가 작습니다.
2. **Shorts는 시청자를 붙잡지 못한다.** 트래픽의 63%가 Shorts 피드인데 고정 시청자는 0.3%입니다. 지나가는 시청이라 구독·재방문으로 이어지지 않습니다.
3. **영어 전환 가설은 철회.** 시청자의 85.5%가 한국이고 자막도 98.4%가 없습니다. 이 채널의 실제 시청자는 한국의 55세 이상 층입니다. 영어권은 데이터 근거 없는 새 시장 도전이며, 한다면 별도 실험으로만 합니다.
4. **구독자 4만 명은 대부분 비활성.** 월간 시청자 2.6천 명, 신규 구독 +12에 순증감 -50이면 감소가 약 62명입니다. Studio의 구독자 감소 원인과 비활성 계정 정리 여부를 확인해야 합니다.
5. **라이브 제목에 "[중간광고없음]"** 이 있습니다. 가장 시청시간이 큰 형식인 라이브의 광고 수익을 스스로 줄이고 있을 가능성이 있습니다(수면 시청자 배려와의 트레이드오프). 실제 광고 설정을 Studio에서 확인해야 합니다.

## 수정된 전략: "한국 55+ 수면·휴식 + 차분한 아침 브리핑"
- **타깃**: 휴대전화와 TV로 보는 한국 중장년층. 썸네일은 큰 글씨 한글, 제목은 짧고 쉬운 말.
- **콘텐츠 2종 분리**
  - 수면 편: 순수 빗소리 1~3시간(중간에 말 없음).
  - 아침 브리핑 편: 5~8분, 오늘 날씨·생활·건강 상식 + 이후 빗소리. 정치·사건사고 제외, 건강 정보는 질병관리청 같은 공식 출처로만 작성.
- **Shorts는 유입 통로**: 주 3개 유지하되 업로드할 때 "관련 동영상"으로 롱폼을 연결하고, 첫 댓글에 롱폼 링크를 고정.
- **라이브 유지**: 신규 시청자 659명을 만든 형식이므로 계속합니다. 광고·슈퍼챗 설정만 점검합니다.
- **구독 유도 멘트**: 롱폼 도입 10초 안에 "구독하고 알림 설정하면 잠들기 전에 바로 들을 수 있어요" 정도의 짧은 안내.
