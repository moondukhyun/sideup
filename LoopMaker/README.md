# LoopMaker v11.19 — 이야기 서재 업그레이드

기존 `LoopMaker_v9.py` 를 이 파일로 교체하면 됩니다 (파일명 그대로라 바로가기·배치파일 안 깨짐).
교체 전에 기존 파일을 `LoopMaker_v9_백업.py` 로 복사해 두세요.
AI 배경 탭의 새 효과(젖은 바위 등)는 `SceneMaker/` 폴더의 수정 파일도 함께 교체해야 합니다.

## 이야기 스타일 (스토리 내레이션 탭 → 이야기 스타일)
| 종류 | 스타일 | 방식 |
|---|---|---|
| 연재형 | 🌙 옛날 옛적 전래동화 / 🧸 세계 명작 동화 / 🌿 포근한 고전 소설 / 🏯 한국 고전·근대 문학 | 목록 순서대로, 영상마다 이어서 |
| 창작형 | 🏡 새로 지은 옛이야기 / 🌲 숲과 호수의 밤 산책 / 🚂 밤 기차·바닷마을 여행 / ☕ 비 오는 날 작은 가게 / 🧘 수면 명상 | 매번 새로 창작 |
| 기존 | 🕯️ 포근한 미스터리 / 🔀 반전 미스터리 / 📚 명작 추리 연재(셜록 홈즈) | 그대로 (진행상태 파일 호환) |

## ▶ 다음에 들려줄 작품 고르기 (연재형)
- 이야기 스타일 아래 드롭다운에서 작품을 고르고 **[이 작품부터]** 를 누르면, 다음 영상은 그 작품부터 시작합니다.
- ▶ 진행 중 / ✅ 이미 들려줌 표시가 붙습니다. 이미 들려준 작품을 고르면 다시 들려줍니다.
- 진행 중인 다른 작품이 있으면 중단할지 물어보고, 중단한 작품은 나중에 처음부터 다시 시작합니다.
- 목록 파일(메모장)을 직접 고쳐도 됩니다: `📚 연재 목록 열기`. 형식 `작가 | 작품 | 메모`, 앞에 `#` 이면 건너뜀.

## 빗소리 크기 방식 (기본: 일정하게)
목소리가 나올 때 빗소리가 줄었다 커지지 않고 처음부터 끝까지 같은 크기입니다 (잠잘 때 소리 변화로 깨지 않게).
`일정하게 · 보통/작게/크게` 와 예전 방식(말할 때 줄이기)을 고를 수 있습니다.

## 유튜브 문구가 이야기 종류를 따라갑니다
영상 첫 화면 제목 카드, 제목, 설명, 태그가 이야기 종류에 맞게 바뀝니다
(전래동화 → "Folk Tale Sleep Story", 수면 명상 → "Sleep Meditation" 등). 예전에는 모든 영상에 "Mystery" 가 붙었습니다.

## Claude 로그인이 풀렸을 때
앱에서 로그인돼 있어도 **이 PC 의 Claude Code 는 따로 로그인**해야 합니다. 로그인 만료·사용량 한도는 이제 몇 분 기다리지 않고
바로 한글 안내와 함께 멈춥니다 (예전에는 샘플 이야기로 영상을 끝까지 만들었음).
해결: 명령 프롬프트(cmd) → `claude` → `/login`
