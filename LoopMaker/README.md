# LoopMaker v11.19 — 이야기 서재 업그레이드

기존 `LoopMaker_v9.py` 를 이 파일로 교체하면 됩니다 (파일명 그대로라 바로가기·배치파일 안 깨짐).
교체 전에 기존 파일을 `LoopMaker_v9_백업.py` 로 복사해 두세요.

## 이야기 스타일 (스토리 내레이션 탭 → 이야기 스타일)
| 종류 | 스타일 | 방식 |
|---|---|---|
| 연재형 | 🌙 옛날 옛적 전래동화 | 목록 순서대로, 영상마다 이어서 |
| 연재형 | 🧸 세계 명작 동화 | 〃 |
| 연재형 | 🌿 포근한 고전 소설 | 〃 |
| 연재형 | 🏯 한국 고전·근대 문학 | 〃 |
| 창작형 | 🏡 새로 지은 옛이야기 | 매번 새로 창작 |
| 창작형 | 🌲 숲과 호수의 밤 산책 | 〃 |
| 창작형 | 🚂 밤 기차·바닷마을 여행 | 〃 |
| 창작형 | ☕ 비 오는 날 작은 가게 이야기 | 〃 |
| 창작형 | 🧘 수면 명상 | 〃 (호흡·몸 이완 안내) |
| 기존 | 🕯️ 포근한 미스터리 / 🔀 반전 미스터리 | 그대로 |
| 기존 | 📚 명작 추리 연재 (셜록 홈즈) | 그대로 (진행상태 파일 호환) |

## 연재 목록 편집
`📚 연재 목록 열기` 버튼 → 현재 선택한 스타일의 목록(메모장)이 열립니다. 형식: `작가 | 작품 | 메모`.
서재마다 목록/진행상태 파일이 따로 생깁니다 (`전래동화_목록.txt`, `전래동화_진행상태.json` 등).
저작권이 끝난 작품만 추가하세요.
